# أنام لإدارة الضيافة

منصة تخطيط وتشغيل لـ **فندق أنام للشقق الفندقية** في حي الحيلة الغربي بمحايل عسير. افتح **index.html** في المتصفح. تعمل الواجهة على الهاتف والكمبيوتر، وتُحفظ البيانات في المتصفح نفسه، ويمكن تصديرها بصيغة JSON. للتثبيت كتطبيق ويب تقدمي، قدّم المجلد عبر HTTPS أو عبر localhost، مثل `py -m http.server 8765 --bind 127.0.0.1` ثم افتح `http://localhost:8765/`.

## بيانات المشروع ومصادرها

## الصفحات

- **لوحة التحكم ولوحة القيادة**: السعة والأسعار والإشغال ومعاملات التكلفة ومدخلات التشغيل والاستثمار، ورسوم الإشغال والإيراد والمصروفات.
- **التشغيل**: الغرف والحجوزات والاستقبال والتدبير والصيانة والمطاعم والفعاليات والقنوات والضيوف.
- **الموارد والرقابة**: المشتريات والمخزون، حسابات الضيوف وإقفال اليوم، المحاسبة، الموظفون والورديات، الهيكل والرواتب، الجودة والسلامة والامتثال، التقارير.
- **التخطيط والاستثمار**: الموقع والخريطة والصور، عقد الإيجار وجدول دفعاته، الرخص والعلامة والمخططات، التجهيزات، بنود التهيئة، إجماليات الاستثمار ومصادر التمويل والمبالغ المدفوعة.

## الافتراضات

الإشغال 75% ومعامل الأسعار وأسعار الليالي ومساحات الوحدات والرواتب وأسعار الخدمات افتراضات تخطيطية قابلة للتعديل من المنصة، وتحتاج تحققًا من سوق محايل عسير. الإيراد والربح التشغيلي قبل التمويل والإهلاك والضرائب. الرصيد غير المفصل بين 7.5 مليون والبنود المحصورة يظهر في صفحة الاستثمار حتى يُستكمل حصر المركبات وتجهيزات المطعم والمقهى والسطح وما قبل الافتتاح ورأس المال العامل.

التشغيل الفعلي ببيانات الضيوف يحتاج حسابات وصلاحيات وقاعدة بيانات خادمية وتكاملات مع الأنظمة المختصة.
